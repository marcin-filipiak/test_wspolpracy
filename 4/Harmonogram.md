# Harmonogram projektu programu „Kalkulator Walut”

## Zakres prac
Projekt obejmuje:
- analizę wymagań biznesowych,
- zaprojektowanie widoków aplikacji (UI/UX),
- integrację z zewnętrznym API kursów walut,
- implementację algorytmów przeliczania,
- testy jednostkowe i manualne,
- sporządzenie dokumentacji końcowej.

## Harmonogram realizacji

| Lp. | Zadanie | Opis | Czas realizacji |
|-----|---------|------|-----------------|
| 1. | Analiza i planowanie | Wybór API walutowego i ustalenie wymagań funkcjonalnych | 2 godz. |
| 2. | Makiety interfejsu | Stworzenie szkiców ekranów dla przelicznika i historii kursów | 3 godz. |
| 3. | Integracja z API | Nawiązanie bezpiecznego połączenia z serwerem dostawcy kursów | 1.5 godz. |
| 4. | Przetwarzanie danych | Napisanie funkcji przeliczających podane kwoty na wybrane waluty | 2.5 godz. |
| 5. | Obsługa przypadków brzegowych | Zabezpieczenie przed brakiem Internetu i błędnymi danymi wejściowymi | 0.5 godz. |
| 6. | Kontrola jakości (QA) | Przeprowadzenie scenariuszy testowych w różnych środowiskach | 2 godz. |
| 7. | Stabilizacja aplikacji | Wdrożenie ostatecznych poprawek przed wydaniem | 3 godz. |
| 8. | Podsumowanie i dokumentacja| Utworzenie pliku README.md i opisu architektury | 1 godz. |
